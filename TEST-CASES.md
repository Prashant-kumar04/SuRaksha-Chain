## App Pages and API URLs

The app is a single-page interface. Use the Render service root URL, log in, and select a case from **Case Dossier**.

- Integrity: **Physical File Integrity** page; API `GET /api/documents/<documentId>/verify-file`
- Drift history/diff: **Version Drift Check** page; APIs `GET /api/documents/<documentId>/versions` and `GET /api/documents/<documentId>/diff?v1=<v1>&v2=<v2>`
- Unseal submit/approve: **Judicial Authorization Workflow (Unseal Registry)**; APIs under `/api/unseal-requests`
- Victim record: **Sec 228A IPC Victim Record**; API `GET /api/cases/<caseId>/victim-record`
- Audit: **Tamper-Evident Audit Ledger** (Court Officer/Admin)

Replace the API paths above with your Render origin, for example `https://your-service.onrender.com/api/...`.
